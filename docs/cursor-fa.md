# استفاده با Cursor

## Persian Product Engineer در Cursor

این Skill به Cursor کمک می‌کند تا هنگام توسعه پروژه‌های فارسی:

- RTL واقعی را رعایت کند.
- استانداردهای UI/UX را رعایت کند.
- از فونت‌های فارسی مناسب استفاده کند.
- تاریخ، اعداد و فرمت‌های ایرانی را درست مدیریت کند.

## Workflow پیشنهادی

1. ابتدا پروژه را تحلیل کن.
2. معماری فعلی را حفظ کن.
3. تغییرات را مرحله‌ای انجام بده.
4. قبل از پایان UI و کد را review کن.

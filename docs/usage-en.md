# Usage Guide

## Purpose

Persian Product Engineer is an AI agent skill for building professional RTL and Persian-first digital products.

## Recommended Workflow

1. Analyze the existing project.
2. Understand architecture before changes.
3. Apply engineering and design rules.
4. Review accessibility, responsiveness and localization.

## Supported Scenarios

- Landing pages
- Dashboards
- Admin panels
- Ecommerce
- Web applications

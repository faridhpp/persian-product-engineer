# استفاده در Codex

## هدف

این Skill به Codex کمک می‌کند پروژه‌های فارسی را با استانداردهای حرفه‌ای توسعه دهد.

## رفتار مورد انتظار

Codex باید:

- قبل از تغییر معماری پروژه را بررسی کند.
- RTL را به صورت واقعی پیاده‌سازی کند.
- فونت و تایپوگرافی فارسی را رعایت کند.
- UI را برای موبایل و دسکتاپ بررسی کند.
- قبل از تحویل review نهایی انجام دهد.

## پیشنهاد

همراه با Skill های عمومی Engineering و Frontend Design استفاده شود.

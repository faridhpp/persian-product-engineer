# راهنمای نصب Persian Product Engineer

## معرفی

این پروژه یک Skill برای Agent های هوش مصنوعی مانند Codex، Cursor و Claude Code است تا در ساخت محصولات فارسی استانداردهای مهندسی، UI/UX و RTL را رعایت کنند.

## استفاده

ریپو را دریافت کنید:

```bash
git clone https://github.com/faridhpp/persian-product-engineer.git
```

سپس پوشه Skill را در مسیر مورد استفاده Agent خود قرار دهید.

## قابلیت‌ها

- طراحی RTL واقعی
- استاندارد فونت فارسی
- تجربه کاربری مناسب کاربران ایرانی
- تاریخ شمسی
- فرمت تومان و ریال
- استانداردهای Frontend
- بررسی کیفیت کد

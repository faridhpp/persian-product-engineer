# Next.js Application Example

## Goal
Use Persian Product Engineer when building a Persian RTL Next.js application.

## Agent Workflow

1. Analyze existing architecture.
2. Verify RTL and typography setup.
3. Define reusable components.
4. Implement feature.
5. Review responsive behavior and accessibility.

## Checklist

- `lang="fa"`
- `dir="rtl"`
- Persian font configured
- Mobile-first layout
- Loading and error states
- SEO metadata
